Health Check-ups

Health checks should help answer a clinical question—not simply create the longest possible list of tests.

The Phase 1 website introduces the available check-up levels without publishing unapproved components or prices. Final inclusions must be populated from the current billing source and reviewed medically.

Patients should be able to call before booking so the team can explain fasting, sample requirements, package inclusions and whether a doctor’s advice is appropriate.

Working package names provided by management are Basic Health Check-up, Advanced Health Check-up, Premium Health Check-up and Cancer Marker Package. The cancer-marker package requires especially careful medical positioning.

Frequently asked

Which package is best for me?

The correct package depends on age, history, symptoms, medicines and clinical goals. The website should not prescribe a package as universally suitable.

Are cancer markers a cancer screening guarantee?

No. Tumour markers are not universal screening tests and must be used in an appropriate clinical context.

Can I book at home?

Yes, subject to the tests included and serviceability.
