# Dr Bhasin's Flu Testing Website

A lightweight static website built with semantic HTML, responsive CSS, and vanilla JavaScript. It has no framework, build step, or package dependencies.

## Structure

```text
index.html
assets/
  css/main.css
  images/
  js/main.js
```

## Use

Open `index.html` directly in a browser, or serve this folder with any static web server.
