# Website fixes — 22 Oct 2026

This folder is a copy of `D:\Bhasin-s-Lab-main-web`, with the fixes below applied.
The original folder was not changed. Compare the two folders (e.g. with WinMerge or
VS Code "Compare Folders") to see every line that changed.

> `.md` files are now blocked from the public site by `.htaccess`, so this note
> stays private even if the whole folder is uploaded.

## Before you upload — required step

The callback form no longer contains the Leads API key. It now posts to
`integrations/callback-form/submit.php`, which adds the key on the server.

1. **Generate a new Leads API key.** The old key was visible to anyone in the old
   `callback-form.html`, so treat it as leaked.
2. On the hosting account, create **`leads-config.php` one level above the web
   root** (for cPanel: in `/home/<account>/`, next to `public_html`, not inside it):

   ```php
   <?php
   return [
       'endpoint' => 'https://labmate.bhasinpathlabs.com:4672/api/v1/leads',
       'api_key'  => 'PASTE-THE-NEW-KEY-HERE',
   ];
   ```
3. Hosting must have PHP with the cURL extension (standard on cPanel).
4. Submit a test enquiry on the live site and check it arrives in the CRM.

Until step 2 is done, the form shows "We could not submit your enquiry. Please call
or WhatsApp the lab." — nothing else on the site is affected.

## What changed

### Bugs fixed
- **Mobile menu did not open on the homepage or the CGHS page.** Two scripts were
  attaching a click handler to the same menu button (open, then immediately close).
  The menu is now handled only by `assets/js/site-header.js`; the duplicate code was
  removed from `assets/js/main.js` and from the inline script in
  `cghs-empanelled/index.html`. The 404 page now loads `site-header.js` too.
- **Flu testing page:** the "Request a callback" pop-up was open on page load and
  covered the hero panel. It now opens only when a callback button is clicked, as a
  proper modal (Esc closes it).
- **Test library page** threw a JavaScript error (it loads the flu page's script,
  which expected the pop-up). The script now checks for the pop-up first.
- **Homepage "Book" step** read "or WhatsApp us…"; now "Call or WhatsApp us…".
- **Homepage service cards that linked back to the homepage:**
  - Walk-in testing → `/24x7-lab.html`
  - Accreditation & quality → the NABL section on the same page (`#accreditation`)
  - Paediatric collection → WhatsApp with a pre-filled message
  - Doctors & institutions → email to query@bhasinpathlabs.com
  Each has a comment noting which page to point to once that page is approved.

### Navigation and SEO
- The header is now **plain HTML in every page** instead of being inserted by
  JavaScript, so search engines and no-JS visitors see the menu and there is no
  layout jump. `assets/partials/site-header.html` is the master copy; if you edit
  the menu, update the partial, the pages, and the string in `site-header.js`.
- Added **"24x7 Lab"** to the main menu and to the footers that lacked it (it was
  in the sitemap but not linked from any menu).
- Current page is highlighted in the menu (`aria-current="page"`).
- Clicking "Tests" / "Government Panels" on desktop now opens their pages
  (previously the click was swallowed). Touch tablets still open the dropdown on
  the first tap.
- Menu stays on one row between 1081 px and 1260 px wide.
- Open Graph / Twitter preview tags added to the homepage, Home Collection and
  Health Checkups (WhatsApp/Facebook link previews).
- `lang="en-IN"` on all pages (was a mix of en, en-GB, en-IN).
- Fixed titles/descriptions: duplicated title on the Financial Microscope article,
  stray whitespace in the About title, internal drafting text in the Careers and
  Medical Specialities meta descriptions.

### Security
- Callback form: API key removed from public code (see required step above),
  server-side validation (Indian mobile number, consent), same-site check, hidden
  honeypot field against bots, limit of 5 submissions per IP per 10 minutes.
- Form now requires a valid Indian mobile number (starts 6–9) in the browser too.
- `.htaccess` now blocks public access to `*.md`, `*.py`, `*.bak`, `*.log`,
  `*.sql`, `TEMPLATE_LICENSE.txt` and any `.git` folder (so the content
  verification register and README cannot be downloaded).

### Design and accessibility
- Mobile homepage: headline and Call/WhatsApp buttons now come first, photo
  carousel below them (the call button is visible without scrolling).
- Carousel: slower (5 s instead of 3 s), new pause/play button, pauses while a
  control has keyboard focus; hidden slides load lazily.
- Heading weight made consistent ("Before you book", "Quality is built…" etc. no
  longer heavy bold next to regular-weight section headings).
- "THE HOME COLLECTION JOURNEY" → "The Home Collection Journey".
- Google review cards: label changed from "Review highlight" to
  "Paraphrased Google review" (see "Still to decide").
- Callback form uses the site font (Poppins) instead of Arial.

### Performance
- Flu page illustrations: ~1.2 MB each → 40–57 KB (same size, visually identical).
- Hero badges: 1254 px → 420 px (109 KB → 30 KB, 56 KB → 20 KB).
- NABL certificate preview: 457 KB → 62 KB.
- 42 images received `width`/`height` attributes to prevent layout shift, plus a
  CSS rule that keeps their natural proportions.
- All changed CSS/JS files have new `?v=20261022` version strings so browsers load
  the new files instead of cached copies.
